# 성적 관리 프로그램 (Week 11)

## ① 무엇을 하나요 (What)
성적 CSV 파일을 읽어 `0~100`점 사이의 유효한 `(이름, 점수)` 목록(`kept`)만 골라내고, 형식이 잘못되었거나 범위를 벗어난 줄은 `(줄번호, 원본줄, 이유)` 형태로 기록(`skipped`)하여 돌려주는 프로그램입니다.

## ② 왜 만들었나요 (Why)
실제 현장에서 수집한 성적 CSV 파일에는 빈 줄, 이름이나 점수가 빠진 줄, 숫자가 아닌 값(`결석`), 허용 범위(`0~100`) 밖의 점수(`105`, `-5`), 쉼표가 포함된 이름(`"최,네번"`), 동명이인 데이터가 섞여 있습니다. 이를 검증 없이 그대로 읽으면 프로그램이 비정상 종료되거나 통계가 왜곡되므로, 프로그램이 죽지 않고 정상 데이터와 오류 내역을 안전하게 분리하기 위해 만들었습니다.

## ③ 어떻게 쓰나요 (How)

### 1. 필수 패키지 설치
```bash
pip install pytest pytest-cov
```

### 2. 프로그램 실행
기본 파일(`scores.csv`)로 실행하거나 원하는 CSV 파일 경로를 인자로 넘겨 실행합니다.
```bash
python load_scores.py scores.csv
```

실행 결과 예시:
```text
읽은 줄 : 5개
  김하나 88
  최,네번 77
  김하나 91
  윤보람 64
  서한별 95
건너뛴 줄 : 5개
  3행  이두리,105   ← 점수가 0~100 밖
  4행  박세찬,   ← 점수가 비어 있음
  7행  정오름,-5   ← 점수가 0~100 밖
  8행  한겨울,결석   ← 점수가 정수가 아님
  9행  장미르,72,비고없음   ← 열 개수가 2가 아님
```

## ④ 어떻게 테스트하나요

### 기본 단위 테스트 실행
```bash
pytest test_load_scores.py
```

통과 화면:
```text
============================= test session starts =============================
collected 12 items

test_load_scores.py ............                                         [100%]

============================= 12 passed in 0.28s ==============================
```

### 커버리지 측정 (안 지나간 줄 확인)
```bash
pytest test_load_scores.py --cov=load_scores --cov-report=term-missing
```

```text

```

### AI 생성 테스트 실행 및 비교
```bash
pytest test_ai_A.py
pytest test_ai_B.py
pytest test_ai_bug.py
```

## ⑤ 파일 구성

| 파일 이름 | 설명 |
| :--- | :--- |
| `load_scores.py` | 성적 CSV 파일을 읽어 유효한 점수(`kept`)와 건너뛴 줄(`skipped`)을 반환하는 핵심 모듈 |
| `test_load_scores.py` | 명세서 기반으로 직접 설계한 정상·예외·경계값 `pytest` 단위 테스트 |
| `test_ai_A.py` | 프롬프트 A (`load_scores.py` 코드를 제공)로 생성한 AI 단위 테스트 |
| `test_ai_B.py` | 프롬프트 B (10주차 명세서 6칸만 제공)로 생성한 AI 단위 테스트 |
| `test_ai_bug.py` | `bug3_logic.py`의 버그 있는 코드를 AI에게 주었을 때 버그(`== 85`)를 굳히는지 확인하는 함정 실험 테스트 |
| `bug3_logic.py` | 8주차 논리 오류(`find_max`, `count_pass`) 실험용 코드 |
| `scores.csv`, `empty.csv`, `weird.csv` | 정상·빈 파일·비정상 케이스 검증용 CSV 데이터 |
| `prompts.txt` | STEP 3 실험에 사용한 A/B 및 함정 프롬프트 원문 |
| `WORKSHEET.md` | 11주차 실습 워크시트 6장(설계표·기록표 ①②·비교표·작성표 ①②) 및 제출용 정리 문서 |
| `LICENSE` | MIT 라이선스 파일 |
